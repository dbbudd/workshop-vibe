App publishing · Getting started

Vercel

Vercel publishes web apps from a GitHub repository. Every change you push to its main branch goes live by itself, and a change on a separate branch gets its own preview link first.

Best for

A tool that has grown past one page, such as a web app Claude Code built. A plain index.html works too.

Exercise 1: Sign up with GitHub

  1. Go to vercel.com and choose Sign Up.
  2. Continue with GitHub, so Vercel can see your repositories.

Exercise 2: Import your repository

  1. Choose Add New…, then Project.
  2. Under Import Git Repository, find your tool’s repository and press Import. Not listed? Choose Configure GitHub App, and let Vercel see it.
  3. Press Deploy. For a plain index.html, leave the settings as they are: Vercel chooses Other, and that works.

Exercise 3: Open your link

When it finishes, Vercel gives your app an address made from the project’s name, ending in vercel.app.

  1. Open the link and try your tool.
  2. Send it to a colleague to test.

Exercise 4: Change it, then preview it

Push a change to the main branch, and Vercel puts it live straight away. Push it to another branch instead, and Vercel makes a preview link, so you can test it before it replaces the live version.

A preview link asks for a Vercel login at first. To let a colleague test one, make a Shareable Link for it. The free plan includes them.
